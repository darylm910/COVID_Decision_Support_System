# COVID Decision Support System

## Overview

This project extends the COVID-19 Mortality Prediction project developed during Springboard Capstone Two by transforming the predictive model into an interactive decision-support system.

The project combines machine learning, explainable AI, unsupervised learning, and interactive visualization to help users better understand the factors associated with country-level COVID-19 mortality.

Current development focuses on preparing data and analytical assets for:

- Explainable AI using SHAP
- Country clustering using unsupervised learning
- Enhanced Streamlit dashboard functionality
- *(Optional)* AI-assisted natural language exploration
